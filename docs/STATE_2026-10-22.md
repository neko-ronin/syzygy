## Capturing, and the one harness gap

- **Any frame that will be counted, measured or judged is shot with `--sequence`.**
  A single shot writes the PNG plus one `shots/latest.json`, and the next single
  shot overwrites it — round 3g's pose-18 frame had no provenance at all
  ([`PITFALLS.md`](PITFALLS.md) §38). A run directory with `_capture.json` is the
  only proof a frame came from a healthy run.
- **Harness fix not made** (named, not forgotten): write `shots/<stamp>-<pose>.json`
  next to each single-mode PNG instead of one shared `latest.json`. It is an edit to
  the harness every capture depends on, so it wants its own control run.
